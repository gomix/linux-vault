YouTube Music Desktop App
* https://ytmdesktop.github.io/ytmdesktop

Installing/Running on my Fedora using `flatpak`.

```
$ flatpak install --system flathub app.ytmdesktop.ytmdesktop
$ flatpak run app.ytmdesktop.ytmdesktop
```
After you login you have your app available, below its running side by side with easyeffects in my Hyprland.
