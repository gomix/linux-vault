My config:

```
hl.config({                                                                                                                      
    input = {                                          
        touchpad = {                           
            natural_scroll = false,                             
            tap_to_click = false,                                                    
        },                                                        
    },                                                       
})     
```

- `natural_scroll` : controls the direction of two-finger scrolling on the touchpad.
- `tap_to_click` : enables tap to single and double click.
